Daskal Live Show: Timecode Visuals

Zori Baazov of DepthLab, a Tel Aviv studio, built a timecode-based visual show for Daskal, a keyboardist, composer and producer, so his live set plays as one audiovisual show. The show has a visual language built for the set, content synced to the music via timecode and a cue list. Zori runs it live at every show.

Role
Zori Baazov (DepthLab): visual show design, timecode and live operation
About the project

The show

The show is built for Daskal's live set and has a visual language of its own. In the gallery, line drawings, clouds, blossom-like textures and dotted patterns move across the wall behind his keyboards, with spiral patterns on the LED columns above.

How it works

The content is locked to the music by timecode, a shared time signal, so each cue lands at the same moment in the music at every show. The cue points of the set are organized in a cue list.

Zori's role

The music is Daskal's, and the visual show is Zori's: he designed it, set up the timecode sync and the cue list, and operates it live at every date.
